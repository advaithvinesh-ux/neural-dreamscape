# Neural Dreamscape — AI & Machine Learning Website

A responsive, animated educational website built with **HTML5 and CSS3** for a first-year AIML web design project.

## Features
- Responsive desktop, tablet, and mobile layouts
- CSS-only mobile navigation menu
- Animated glowing neural-network artwork
- Enhanced CSS animations: flowing network connections, pulsing nodes, glowing title, drifting labels, floating pills, and animated cards
- Expandable AI / ML / deep-learning cards using native HTML `<details>`
- Sections explaining neural networks and a beginner learning roadmap
- No JavaScript, backend, or database required

## Run locally
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a browser.

The optional Google Fonts import needs an internet connection; fallback fonts are provided.

## Publish with GitHub Pages
1. Create a public repository named `neural-dreamscape`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. After deployment, the site will be available at `https://YOUR-USERNAME.github.io/neural-dreamscape/`.

## Technologies
- HTML5 semantic elements
- CSS Grid and Flexbox
- CSS media queries
- CSS custom properties
- CSS keyframe animations and transitions
- Native HTML details/summary interaction

## Academic note
This is a static educational website. It does not generate AI images or run a machine-learning model; it introduces AI concepts through a designed web experience.
